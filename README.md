# Audition Room

Run musical auditions from three devices: singers check in, the pianist gets their music and a live queue, and the music director logs ranges and casts characters.

## Try the prototype

Open `prototype/index.html` in a browser. Outside the Claude artifact platform it runs in device-only mode, so data won't sync between devices yet.
